3주차 로또 미션

기능 목록

1. 로또 구매

[ ] 로또 구입 금액을 입력받는다.
[x] [예외] 구입 금액이 1,000원으로 나누어떨어지지 않는 경우
[x] [예외] 구입 금액이 숫자가 아닌 경우
[x] [예외] 구입 금액이 1,000원 미만인 경우
[ ] 구입 금액만큼 로또를 발행한다.
[ ] 발행된 로또의 개수와 번호(오름차순 정렬)를 출력한다.

2. 당첨 번호 입력

[ ] 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.
[ ] [예외] 당첨 번호가 6개가 아닌 경우
[ ] [예외] 당첨 번호의 범위가 1~45가 아닌 경우
[ ] [예외] 당첨 번호에 중복된 숫자가 있는 경우
[x] [예외] 당첨 번호에 숫자가 아닌 값이 있는 경우
[ ] 보너스 번호 1개를 입력받는다.
[ ] [예외] 보너스 번호의 범위가 1~45가 아닌 경우
[x] [예외] 보너스 번호가 숫자가 아닌 경우
[x] [예외] 보너스 번호가 이미 당첨 번호에 포함된 경우

3. 당첨 통계 계산

[ ] 사용자가 구매한 모든 로또와 당첨 번호를 비교하여 당첨 등수를 결정한다.
[ ] 5등: 3개 일치 (5,000원)
[ ] 4등: 4개 일치 (50,000원)
[ ] 3등: 5개 일치 (1,500,000원)
[ ] 2등: 5개 일치 + 보너스 볼 일치 (30,000,000원)
[ ] 1등: 6개 일치 (2,000,000,000원)
[ ] 총 수익률을 계산한다. (소수점 둘째 자리에서 반올림)

4. 결과 출력

[ ] 당첨 통계(등수별 당첨 개수)를 형식에 맞게 출력한다.
[ ] 최종 수익률을 형식에 맞게 출력한다.

5. Lotto 클래스 예외사항

[x] 로또 번호의 개수가 6개가 아니면 예외를 발생시킨다.
[x] 로또 번호에 중복된 숫자가 있으면 예외를 발생시킨다.
[x] 로또 번호의 범위가 1~45가 아니면 예외를 발생시킨다.
